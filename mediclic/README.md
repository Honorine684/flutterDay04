# Mediclic - Application de Gestion Médicale pour Patients

Mediclic est une application mobile conçue pour les patients, leur permettant de rechercher des médecins, de prendre des rendez-vous et de consulter leur dossier médical en toute simplicité.

---

## Fonctionnalités

- **Recherche de médecins** :
  - Trouvez des médecins par spécialité, nom ou localisation.
  - Consultez les disponibilités et les créneaux horaires des médecins.

- **Prise de rendez-vous** :
  - Prenez des rendez-vous en ligne avec un médecin de votre choix.
  - Recevez une confirmation immédiate de votre rendez-vous.

- **Dossier médical** :
  - Consultez votre dossier médical complet (consultations, examens, traitements).
  - Exportez votre dossier médical au format PDF.

- **Authentification sécurisée** :
  - Connexion sécurisée pour protéger vos données personnelles.

---
