# Mediclinique - Application de Gestion Médicale

Mediclinique est une application Flutter conçue pour les professionnels de santé afin de gérer les dossiers médicaux des patients, planifier des consultations et suivre les traitements.

## Fonctionnalités

- **Gestion des patients** :
  - Ajouter, modifier et consulter les informations des patients.
  - Consulter les antécédents médicaux, les allergies et les traitements en cours.

- **Consultations** :
  - Planifier et enregistrer des consultations.
  - Ajouter des notes, des diagnostics et des plans de traitement.

- **Dossier médical** :
  - Accéder à l'historique complet des consultations et des examens d'un patient.
  - Exporter le dossier médical au format PDF.

- **Authentification** :
  - Connexion sécurisée pour les médecins et les professionnels de santé.

## Prérequis

- Flutter SDK (version 3.0 ou supérieure)
- Dart (version 2.17 ou supérieure)
- Firebase (pour l'authentification et la base de données)
